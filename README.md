# RigForge

Сайт для подбора комплектующих ПК. Можно выбрать детали из каталога, собрать из них сборку, задать бюджет и сохранить несколько вариантов.

Сайт: https://sonjiwu2.github.io/rigforge/

## Что умеет

- **Каталог** — 9 категорий (процессоры, материнские платы, видеокарты, память, SSD, HDD, блоки питания, корпуса, охлаждение), фото у каждой модели, поиск по названию, фильтры по производителю, цене и основным параметрам, сортировка по популярности, цене и оценке.
- **Подробности о детали** — характеристики, цены в магазинах, статистика цены за 90 дней, описание серии из Википедии (для процессоров и видеокарт), отзывы.
- **Валюта** — переключатель GBP / USD / RUB в шапке, все цены, бюджет и экспорт пересчитываются по текущему курсу.
- **Отзывы** — можно поставить оценку от 1 до 5 звёзд и написать отзыв, средняя оценка видна в карточке.
- **Сборка** — по одной детали каждого типа, замена и удаление, сумма, бюджет и остаток.
- **Сохранённые** — сохранение сборок в браузере, переименование, копирование, удаление, скачивание списка в `.txt` и всех сборок в `.json`.
- Работает на телефоне, планшете и компьютере.

## Технологии

Vite + Vanilla JavaScript (без фреймворков), обычный CSS. Сборки, отзывы и выбранная валюта хранятся в `localStorage` этого браузера, сервера и аккаунтов нет.

## API

Основной источник — [VantaSpec](https://vantaspec.com/api-docs) (раздел Shopping в [public-apis](https://github.com/public-apis/public-apis#shopping)): цены британских магазинов и характеристики, без ключа, HTTPS, CORS.

- `GET /api/compare?slugs=...` — данные и характеристики моделей (до 4 за запрос);
- `GET /api/products/price-intelligence?productId=...` — статистика цены за 90 дней.

Поиск VantaSpec (`/api/products/search`) не отдаёт CORS-заголовок, поэтому из браузера его вызвать нельзя. Список моделей для каждой категории лежит в `src/data/catalog.js`, а цены и характеристики по ним загружаются из API при открытии категории. Поиск и фильтры работают по загруженной категории.

«По популярности» — сортировка по числу магазинов, где продаётся модель, затем по избранному на VantaSpec и числу отзывов.

Курсы валют — [Currency-api](https://github.com/fawazahmed0/exchange-api) (раздел Currency Exchange в public-apis), без ключа, обновляется раз в день. Цены в магазинах в фунтах, в долларах и рублях показан пересчёт по курсу.

Дополнительно — [Wikipedia Action API](https://www.mediawiki.org/wiki/API:Main_page) для блока «О серии» (только если серия точно определяется по названию модели).

Ограничения: цены только по магазинам Великобритании, доллары и рубли — пересчёт. Цена в сборке — на момент добавления. Отзывы VantaSpec не отдаёт, поэтому на сайте только отзывы, написанные в этом браузере. Совместимость деталей сайт не проверяет.

## Запуск

```bash
npm install
npm run dev
```

Сборка и просмотр production-версии:

```bash
npm run build
npm run preview
```

## Структура

```
src/
  main.js                     состояние приложения и связь разделов
  api/
    vantaspec.js              запросы к VantaSpec, ошибки, кеш
    currency.js               курсы валют
    wikipedia.js              описание серии из Википедии
  core/
    products.js               приведение данных к одному виду, фильтры, сортировка
    storage.js                localStorage
    reviews.js                отзывы и средняя оценка
  components/
    icons.js                  SVG-иконки
    artwork.js                фото деталей и заглушки
  features/
    catalog/view.js           каталог: поиск, категории, фильтры
    details/dialog.js         окно с подробностями о детали
    build/view.js             текущая сборка и бюджет
    build/export.js           скачивание списков
    saved/view.js             сохранённые сборки
  utils/format.js             форматирование и пересчёт цен
  data/                       список моделей и данные о фото
  styles/                     общие стили, styles/views/ — стили разделов
  assets/                     шрифты и иконки
public/
  assets/                     фото, заглушки, иконка сайта
  licenses/                   тексты лицензий
docs/architecture.md          как устроено приложение
```

Подробнее про состояние, данные и обработку ошибок — в [docs/architecture.md](docs/architecture.md).
